# Sensor Blocker

Android app to block specific apps from accessing gyroscope, accelerometer, compass (magnetometer) sensors.

## Goal
Prevent selected apps from obtaining data from:
- Gyroscope
- Accelerometer
- Compass / Magnetometer

Note: These are typically zero-permission sensors on stock Android. Implementation may require root, custom ROM (e.g. GrapheneOS Sensors permission), or monitoring + system-level interventions.
